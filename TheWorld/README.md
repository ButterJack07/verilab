# The World · 文明经营游戏

一个基于纯 HTML 静态页面的放置类模拟经营游戏。打开即玩，无需任何依赖。

## 运行方式

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管：

```bash
# 例如用 Python
python -m http.server 8080
```

## 当前功能

### 地图
- 30 × 20 网格地图，陆地 / 海洋两种地形
- 海洋贴边生成且整体连通，水域比例控制在 15%–30%
- 莫兰迪色系配色（米白背景、灰蓝海洋、灰绿陆地），无渐变
- 地图由种子确定性生成，刷新页面地图保持不变

### 建筑与小人
- **茅草屋**：地图中心区域随机陆地生成，每 10 秒产出食物，产出量 = 当前人口数，可容纳 5 人
- **小人**：静态圆形单位，占据一格，逐圈扩散寻找陆地生成、互不重叠；每 20 秒增长 1 人，上限为茅草屋容量

### 物品栏
- 8 列 × 4 行连续网格（42px/格），分割线样式与地图一致
- 支持 1×1、1×2、2×2 等多格物品（木材、石头、铁矿、食物、布匹、金矿、木板、砖块）
- **拖动**：默认每次拖动 1 个物品；按住 2 秒（出现金色描边、「整组」角标与「整组移动」气泡提示）再拖动则为整组移动
- 物品可在栏内拖动、堆叠合并，目标区域显示天蓝色描边预览（带柔光）；拖到同种物品堆上自动合并数量
- 放置校验：越界 / 与其他物品重叠时不允许放置

### 合成器
- 3×3 连续网格（42px/格）
- 物品可在物品栏与合成器之间双向拖动（同样支持拖 1 个 / 长按 2s 拖整组），同类自动堆叠
- **合成配方**：网格内材料满足配方时，下方显示可合成成品与「合成」按钮，点击后消耗材料、成品进入物品栏；物品栏满时无法合成
  - 木板 = 2 木材
  - 砖块 = 2 石头 + 1 铁矿
  - 布匹 = 1 木材 + 1 石头
  - 金矿 = 2 铁矿 + 1 木材

### 时间与速度
- 游戏循环 500ms 一次 tick，1 倍速 = 0.5 秒/天，2 倍速 = 0.25 秒/天
- 日期逐天显示（2 倍速下每个中间天都会经过），一年 365 天，标题下实时显示「X 年 X 天」
- 左上角圆形按钮循环切换：1倍速 → 2倍速 → 暂停
- 右上角显示人口（当前 / 容量）与文明程度（每次产出食物 +人口数）

### 操作
- **重新开始**（左上角）：生成新种子，重新生成整张地图与游戏状态
- **地图悬停**：显示当前单元格坐标

## 数据持久化

- 地图种子保存在 `localStorage`（key: `tw-seed`），刷新页面不换地图
- 游戏状态保存在 `localStorage`（key: `tw-game`），每 5 个 tick 自动保存，含人口、小人位置、茅草屋位置、文明程度、日期、物品栏与合成器内容
